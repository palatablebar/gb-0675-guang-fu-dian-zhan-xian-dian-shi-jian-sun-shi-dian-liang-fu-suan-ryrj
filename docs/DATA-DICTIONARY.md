# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。

每条记录必须带场站列。设备与事件的正式身份=场站+原编号（如 北岭/INV-A、南岭/E-01）；两站同名编号各自独立，去重、冲突判定、事件并集、对照选取、损失积分全部按复合键进行，不按原编号跨站合并。场站为空或未登记的记录隔离待查，保留原值与原始行号，不落任何场站，不填0。

每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例北岭 INV-A 的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟；南岭同名 E-01 独立成30分钟并集。

基线只采用同场站、同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台，跨站不借用。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。

每片段损失=max(基线−实际,0)×秒数/3600。实际高于基线时损失0。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。

对账分两级：场站内事件并集时长=切片时长、基准电量=实际电量+非负损失各自对平；区域合计=各站结果之和，另按全批直接合计复核，出现未归集到登记场站的行时两口径相抵，区域不可加总，批次不得归档。事件依据、遥测依据、对照依据均以 场站/编号 形式留痕。

双站完整批：北岭 INV-A 基线100kW、实际60kW、并集30分钟、损失20kWh；北岭 INV-B 基线50、实际30、20分钟、损失6.6667kWh；南岭 INV-A 基线100、实际80、30分钟、损失10kWh。区域确定损失36.6667kWh=26.6667+10.0000。能量核验按实际+非负损失计算可解释基准电量。

同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离、无未定片段且区域可加总。此工具供离线复算，不包含生产控制或电网调度。
